CONFIRMAÇÃO

Instalar no sistema?

O M.U.T.A.T.E. converterá o pacote para o formato nativo e solicitará autorização de administrador pelo PolicyKit. Scripts de instalação do pacote poderão ser executados com privilégios elevados.
REPOSITÓRIO NATIVO

Instalar aplicativo?

O gerenciador de pacotes do Linux instalará o aplicativo e suas dependências. A versão será escolhida conforme os repositórios habilitados, e scripts do pacote poderão ser executados como administrador.
